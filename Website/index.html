Generate the complete hair control setup

mehigo Hair Manager creates or updates the Animator Controller and Layers, Animation Clips, Expression Menu, Parameters, and Material Swap controls, then configures the required Modular Avatar components. Modular Avatar remains the core dependency and performs the non-destructive integration at build time.

Gesture Manager visuals when installed
