Create VRChat hairstyle menus without the setup headache

mehigo Hair Manager is a guided VRChat hairstyle switcher and hair menu tool for Unity. Add hairstyles, hair toggles, BlendShape radial controls, color presets, captured icons, and Modular Avatar integration from one editor window.

A focused workflow for VRChat hair customization

Simple Mode handles common setup automatically, while Advanced Mode keeps detailed compatibility and generation controls available when needed.

✦

Hairstyle switcher

Add multiple Hair Objects from the Hierarchy, drag and drop, reorder them, and generate a VRChat Expressions Menu.

◉

Toggle and Radial controls

Choose detected BlendShapes without manually finding their renderer. Create Toggle or Radial Puppet controls in a few clicks.

●

Hair-color presets

Create color buttons from material slots while the current hairstyle materials are preserved automatically as Default.

▣

Custom hairstyle icons

Use bundled icons, choose a Project texture, or capture a square icon directly from the current Unity Scene View.

⌁

Real-time Menu Preview

Inspect hairstyle submenus, Toggle states, Radial controls, page navigation, and color presets before generating assets.

◇

Modular Avatar workflow

Generate Merge Animator, Parameters, and Menu Installer components without modifying the avatar's original expression assets.

Three simple steps

Select the avatar

The VRC Avatar Descriptor and avatar-specific output folder are detected automatically.

Add hair and controls

Add hairstyles, icons, BlendShape controls, linked objects, and hair colors from compact Hair Cards.

Preview and generate

Check the radial menu, validate the setup, and create or update every required asset with one button.

Preview first, test with confidence

The built-in preview mirrors the generated hierarchy and can use Gesture Manager UI assets when they are installed.

  • Separate output folder for every avatar instance
  • Existing setup loading and safe updates
  • Automatic conflict scan before generation
  • Thai and English editor interface
  • Advanced compatibility controls when required

Install with VRChat Creator Companion

Requires Unity 2022.3, VRChat Avatars SDK, and Modular Avatar.
