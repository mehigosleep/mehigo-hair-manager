Unity Editor Tool · Version 1.2.0

VRChatの髪型切り替えメニューを、もっと簡単に

mehigo Hair Managerは、VRChatアバターの髪型切り替え、BlendShapeのToggle・Radial、髪色変更、アイコン撮影、メニュープレビューをまとめて設定できるUnity Editorツールです。

VCCにリポジトリを追加 日本語ガイドを読む

リポジトリURL: https://mehigosleep.github.io/mehigo-hair-manager/vpm.json

髪型改変に必要な機能をひとつの画面に

Simple Modeは一般的な設定を自動化し、細かな調整が必要な場合はAdvanced Modeに切り替えられます。

✦

髪型切り替えメニュー

Hierarchyから複数の髪型を追加し、順番を並べ替えてExpressions Menuを自動作成します。

◉

Toggle・Radial

検出されたBlendShapeを選ぶだけで、ON/OFFボタンやRadial Puppetを追加できます。

●

髪色プリセット

現在のMaterialをDefaultとして自動保存し、複数の髪色ボタンを作成できます。

▣

髪型アイコン

付属アイコン、Project内のTexture、Scene Viewからのキャプチャに対応しています。

⌁

リアルタイムプレビュー

生成前に髪型、BlendShape、髪色、ページ構成をラジアルメニューで確認できます。

◇

Modular Avatar対応

元のFX ControllerやExpressions Menuを直接変更せずに必要なコンポーネントを生成します。

3ステップでセットアップ

アバターを選択

VRC Avatar Descriptorとアバター専用の出力フォルダを自動検出します。

髪型とコントロールを追加

髪型、アイコン、BlendShape、連動オブジェクト、髪色をHair Cardから追加します。

プレビューして生成

メニューを確認し、必要なAnimator・Menu・Parameterをまとめて生成または更新します。

生成前の確認から実機テストまで

プレビューでメニュー構造を確認し、Gesture Managerを使ってUnity上で生成結果をテストできます。

  • アバターごとに出力フォルダを分離
  • 既存セットアップの読み込みと安全な更新
  • 生成前の自動Conflictチェック
  • 日本語ガイド、英語・タイ語UI
  • 必要に応じてAdvanced設定を利用可能

VRChat Creator Companionからインストール

Unity 2022.3、VRChat Avatars SDK、Modular Avatarが必要です。
