## Modular Avatar

[Modular Avatar](https://modular-avatar.nadena.dev/) by bd_ is the required core dependency. mehigo Hair Manager generates and configures the control assets and Modular Avatar components; Modular Avatar performs the non-destructive integration at avatar build time.

## Gesture Manager — optional Menu Preview integration

When [Gesture Manager](https://github.com/BlackStartx/VRC-Gesture-Manager) is installed by the user, mehigo Hair Manager can locate and display UI textures from that installed package in its editor-only Menu Preview.

- Gesture Manager is optional.
- Gesture Manager files and UI assets are not bundled or redistributed with mehigo Hair Manager.
- Gesture Manager UI assets are not copied into generated avatar assets.
- Without Gesture Manager, Menu Preview uses the built-in mehigo fallback visuals.
- Source: https://github.com/BlackStartx/VRC-Gesture-Manager
